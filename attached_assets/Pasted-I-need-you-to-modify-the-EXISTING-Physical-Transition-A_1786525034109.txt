==================================================
PRODUCT PURPOSE
==================================================

This application is a Physical Transition Assistant.

It is designed for a person who often knows exactly what needs to be done but has difficulty transitioning physically into action.

The problem is especially:
- lying in bed → getting up
- room → room
- intention → physical movement
- phone → task
- one task → another task
- having many things to do → knowing where to start
- continuing a physical task once started
- becoming stuck/frozen during transitions

The product should reduce cognitive load.

Core principle:

"Don't think about the whole day.
Just move to the next station."

The application should feel like an external mind:
- clear
- direct
- minimal
- predictable
- adaptable
- non-shaming
- not emotionally intense
- not overly verbose

It should tell the user the next physical action.

4. STARTING A TASK
==================================================

There must be NO Start button.

1. identify checkpoint
2. verify it is the current expected checkpoint OR an explicitly allowed missed checkpoint
3. change state to IN_PROGRESS
4. record start timestamp
5. start timer automatically
6. show active task screen
7. instruct user to park phone
8. allow user to leave phone
