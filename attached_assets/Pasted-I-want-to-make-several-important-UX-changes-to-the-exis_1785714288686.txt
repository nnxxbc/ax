I want to make several important UX changes to the existing Physical Transition Assistant. Please modify the existing application rather than rebuilding it from scratch.

## 1. MAKE THE CURRENT TASK MUCH BIGGER

The current active task screen has too much empty space and the actual task name is too small.

When a task is in progress, the task name should be the **dominant element on the screen**.

For example:

STRETCH
+
FOAM ROLL

The task name should be large enough to immediately understand from a quick glance.

The current timer should also be prominent but secondary to the task name.

The screen hierarchy should be:

1. Task name — VERY LARGE
2. Timer — LARGE
3. Phone parking instruction — clear but smaller
4. Add Time buttons — easy to access
5. Minimal navigation

The user should be able to understand the screen in less than one second.

The active task screen should feel extremely simple and focused.

# 2. REMOVE THE "DONE" BUTTON COMPLETELY

There should be NO "Done" button on the active task screen.

The task must ONLY be completed by scanning the SAME NFC tag again.

The intended flow is:

1. User arrives at station.
2. User scans NFC tag.
3. Task automatically starts.
4. Timer automatically starts.
5. User parks the phone on the magnetic phone holder.
6. User physically leaves the phone.
7. User performs the task.
8. User returns.
9. User picks up the phone.
10. User scans the SAME NFC tag again.
11. Task is automatically completed.

The app should never ask the user to press "Done" during the normal flow.

The second NFC scan is the completion action.

The UI should clearly communicate this.

For example, while a task is running:

STRETCH + FOAM ROLL

09:32

PARK YOUR PHONE

Leave it here and do your task.

When the user returns to the phone, the screen should show:

STRETCH + FOAM ROLL

09:32

RETURN & SCAN

Scan the same NFC tag to complete.

The UI should make it very clear that the task is waiting for the second NFC scan.
